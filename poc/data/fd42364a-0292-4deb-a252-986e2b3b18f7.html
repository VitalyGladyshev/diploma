3.1.12.4 Сечения модели

Для визуального анализа 3D-объектов, скрытых внутри других, предназначены команды группы «Применение сечения»  на панели «Вид»:

• «Без применения сечения»  отменяет отображение сечения;

[Изображение 218: ]

• «Сечение плоскостью»  формирует сечение плоскостью, перпендикулярной направлению взгляда и проходящей через центр вращения сцены. Положение плоскости (смещение и углы поворота) может быть изменено с помощью манипулятора, расположенного в центре (рис. Моделирование.109);

[Изображение 219: ]

• «Сечение параллелепипедом»  формирует сечение параллелепипедом. Размеры параллелепипеда могут быть изменены с помощью манипуляторов в 3D-сцене;

[Изображение 220: ]

• «Сечение октантом»  формирует сечение в виде октанта. Положение октанта регулируется манипулятором в 3D-сцене;

[Изображение 221: ]

• «Задать ориентацию сечения»  обновляет сформированное сечение после изменения точки обзора сцены;

[Изображение 222: ]

• «Показать объект сечения»  отображает объект, формирующий сечение;

[Изображение 223: ]

• «Виртуальное сечение»  формирует сечение плоскостями или по зонам с заданием набора параметров.

Манипулятор управления положением плоскости сечения в 3D-сцене

Рисунок Моделирование.109

Для всех вариантов создания сечения доступен динамический просмотр результатов построения в 3D-сцене.

В контексте создания сечения к модели возможно применять операции построения объектов и измерения, также допустимы к использованию различные режимы (например, режим контекстного редактирования, режим эскиза и др.).

В результате выполнения команды модель отображается усеченной созданным сечением. При этом для виртуальных сечений и сечений, созданных плоскостью, существует возможность выбирать в 3D-сцене компоненты, грани, ребра и другие объекты модели, которые стали видны в результате создания сечения (рис. Моделирование.110).
